# Endless mode's patterns. How to write these: docs/level-format.md ("endless.txt").
#
# Each [level N name] section is one pattern (N from 1 to 15), written like a level from @0:00 (seconds as played on
# Hard). A pattern plays the same on every difficulty: no difficulty tags and no per-difficulty numbers. Endless
# builds each wave from a budget of pattern levels (tuning.txt [endless]), so a pattern's level is how hard it is
# on its own: about the typing speed it asks for. Guidelines for writing them (the Sim checks them, the game
# doesn't), counting each ship's word, its shield's (the same word again), its turret's (4 letters), for a
# stealth ship one of its missiles (3 letters), and for a diving suicide ship (medium) 3 letters more:
#   level = floor((letters + words) / (spawn time + 3) / 0.8 - 1.4)    spawn time: first ship to last, in seconds
#   spawn time = (letters + words) / (0.8 x level + 1.12) - 3
#   letters from (level + 1) x 3 to (level + 1) x 5
#   and at least half of the diving suicide ships come in from the side or the bottom and move 5 squares or more
#   before they dive (straight down from the top with a short move gives the player no time)
# dotnet run --project src/Sim -- endless --patterns lists every pattern against these.
